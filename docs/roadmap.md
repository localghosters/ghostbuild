# Roadmap

Nothing on this page is implemented unless it is listed under "Done". It is a list of
ideas, not a promise or a schedule. Open an issue to discuss or claim an item.

## Done (0.1.0)

- Python adapter (wheel and sdist), exact SHA-256 comparison
- Docker rebuild and an explicit same-host fallback
- Terminal, JSON and HTML reports
